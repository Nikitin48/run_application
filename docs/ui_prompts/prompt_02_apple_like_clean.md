# Prompt 02 — Apple-like Clean

Сгенерируй мобильный интерфейс приложения **Run Application** в стиле **Apple-like Clean**.

## Креативное направление
- Атмосфера: спокойствие, премиальность, фокус на контенте.
- Визуальный характер: светлое пространство, много воздуха, аккуратные акценты.
- Полностью новый дизайн, не повторяющий текущие решения.

## Визуальная система
- Цвета:
  - базовые: белый, светло-серые нейтрали;
  - акцент: мягкий синий / бирюзовый;
  - темная тема: graphite + clean contrast.
- Минимум декоративных эффектов, максимум функциональной ясности.
- Типографика: аккуратная иерархия, отличный вертикальный ритм.
- Иконки лаконичные, единый вес и стиль.

## UX приоритеты
- Предельно понятный первый опыт (onboarding и auth).
- Явные блоки метрик без визуального шума.
- Высокая читабельность на бегу и в движении.
- Сильная информационная архитектура: что важно сейчас, что вторично.

## Обязательные экраны
1. Onboarding (3 экрана)
2. Login / Register
3. Home / Map
4. Active Run Tracking
5. Run Result
6. History
7. Run Details
8. Leaderboard
9. Profile
10. Settings

## Компоненты
- Кнопки и поля с четкими состояниями (normal/focus/error/disabled)
- Карточки статистики с понятной иерархией
- Списки истории с быстрым сканированием
- Табы и фильтры периода (day/week/month)
- Toast/alert/empty state/loading

## Контент и микрокопирайт
- Короткие спокойные фразы: "Сегодня хороший темп", "Отличный прогресс".
- Минимум текста, максимум смысла.
- Подсказки в нужный момент, без навязчивости.

## Ограничения и результат
- Mobile first (iOS + Android), сетка 8pt.
- Поддержка light/dark.
- Подготовить дизайн-систему токенов и интерактивный прототип.
