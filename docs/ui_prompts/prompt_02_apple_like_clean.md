# Prompt 02 — Apple-like Clean

Сгенерируй мобильный интерфейс приложения **Run Application** в стиле **Apple-like Clean**.

## Креативное направление
- Атмосфера: спокойствие, премиальность, фокус на контенте.
- Визуальный характер: светлое пространство, много воздуха, аккуратные акценты.
- Полностью новый дизайн, не повторяющий текущие решения.

## Визуальная система
- Цвета:
  - базовые: белый, светло-серые нейтрали;
  - акцент: мягкий синий / бирюзовый;
  - темная тема: graphite + clean contrast.
- Минимум декоративных эффектов, максимум функциональной ясности.
- Типографика: аккуратная иерархия, отличный вертикальный ритм.
- Иконки лаконичные, единый вес и стиль.
- Карта и тайлы территорий:
  - neutral: very light gray;
  - my territory: soft blue;
  - opponent territory: calm purple;
  - contested: warm orange;
  - disabled/unavailable: muted gray.
- Тайлы карты должны быть цвето-тематическими и управляться токенами (смена палитры без редизайна компонентов).

## UX приоритеты
- Предельно понятный первый опыт (onboarding и auth).
- Явные блоки метрик без визуального шума.
- Высокая читабельность на бегу и в движении.
- Сильная информационная архитектура: что важно сейчас, что вторично.
- Минимум когнитивной нагрузки: каждое действие сопровождается короткой и понятной подсказкой.

## Обязательные экраны
1. Onboarding (3 экрана)
2. Login / Register
3. Home / Map
4. Active Run Tracking
5. Run Result
6. History
7. Run Details
8. Leaderboard
9. Profile
10. Settings

## Полный функционал приложения (должен быть отражен в UI)
- Онбординг: ценность приложения, принципы трекинга, объяснение территорий, настройка целей.
- Auth:
  - sign in/sign up;
  - восстановление пароля;
  - social auth;
  - inline validation, friendly error states.
- Home/Map:
  - карта с тайлами и понятной легендой;
  - текущий прогресс дня/недели;
  - быстрый запуск пробежки;
  - блок персональных рекомендаций ("лучшее время для пробежки", "цель дня").
- Active Run Tracking:
  - таймер, дистанция, pace, калории;
  - GPS-индикатор качества сигнала;
  - pause/resume/finish + подтверждение;
  - режим "focus view" для чтения метрик на ходу.
- Run Result:
  - итоги, сравнение с медианой последних пробежек;
  - влияние на территорию и место в рейтинге;
  - прогресс к достижениям и следующему уровню.
- History:
  - список тренировок, группировка по неделям/месяцам;
  - фильтры и сортировка;
  - быстрый переход в детали пробежки.
- Run Details:
  - карта маршрута;
  - сплиты и тренды темпа;
  - ключевые метрики и заметки.
- Leaderboard:
  - глобальный/друзья/локальный;
  - период day/week/month;
  - мягкий акцент на росте позиции.
- Profile:
  - карточка пользователя;
  - streak, рекорды, сводные метрики;
  - блок достижений и прогресса.
- Settings:
  - аккаунт, уведомления, приватность;
  - интеграции с системами здоровья;
  - управление темой и цветовой схемой карты.
- Future module (обязательно предусмотреть): самостоятельный раздел **Achievements/Ачивки** (категории, прогресс, редкость, условия разблокировки, детали ачивки).

## Компоненты
- Кнопки и поля с четкими состояниями (normal/focus/error/disabled)
- Карточки статистики с понятной иерархией
- Списки истории с быстрым сканированием
- Табы и фильтры периода (day/week/month)
- Toast/alert/empty state/loading
- Карточки достижений + индикаторы прогресса
- Легенда карты с настройкой цветов тайлов

## Контент и микрокопирайт
- Короткие спокойные фразы: "Сегодня хороший темп", "Отличный прогресс".
- Минимум текста, максимум смысла.
- Подсказки в нужный момент, без навязчивости.

## Ограничения и результат
- Mobile first (iOS + Android), сетка 8pt.
- Поддержка light/dark.
- Подготовить дизайн-систему токенов и интерактивный прототип.
- Обязательно показать 1-2 варианта цветовых схем тайлов карты (переключение в настройках/карте).
