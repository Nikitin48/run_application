# Prompt 03 — Gamified Bold

Сгенерируй мобильный интерфейс приложения **Run Application** в стиле **Gamified Bold**.

## Креативное направление
- Атмосфера: соревнование, челленджи, рост уровня, награды.
- Визуальный характер: смелые акценты, динамичные карточки, игровой прогресс.
- Нужен новый дизайн с нуля, без повторения текущего интерфейса.

## Визуальная система
- Цвета:
  - база: глубокий темный фон или насыщенный светлый фон;
  - акцент 1: яркий оранжевый/коралловый (энергия);
  - акцент 2: синий/фиолетовый (прогресс и статус).
- Крупные числовые блоки и визуально заметные показатели прогресса.
- Карточки достижений с уровнем, бейджем и кратким описанием.
- Иконки более экспрессивные, но единообразные.
- Карта и тайлы:
  - neutral: muted slate;
  - мои территории: bright green;
  - соперники: purple/red;
  - contested: orange with pulse accent;
  - special/rare zones: gradient highlight.
- Цвет тайлов должен поддерживать несколько режимов палитры (competitive, calm, accessibility-safe).

## UX приоритеты
- Сразу показывать "что делать дальше": старт, цель, челлендж.
- Видимый прогресс: daily goal, streak, level-up.
- Сильная мотивация на экране результата и профиля.
- Лидерборд должен быть эмоциональным, но читаемым.
- У каждой ключевой цели должен быть понятный визуальный путь: текущий статус -> шаг до завершения -> награда.

## Обязательные экраны
1. Onboarding (3 экрана с фокусом на челленджах)
2. Login / Register
3. Home / Map (цель дня + кнопка старта)
4. Active Run Tracking
5. Run Result (очки, достижения, территория)
6. History
7. Run Details
8. Leaderboard (анимация/акцент на позиции)
9. Profile (уровень, серия дней, награды)
10. Settings

## Полный функционал приложения (должен быть отражен в UI)
- Onboarding:
  - игровой pitch продукта;
  - объяснение механики территорий;
  - объяснение очков, уровней, серий и наград.
- Auth:
  - login/register;
  - social sign in;
  - forgot password;
  - состояния ошибок и успеха.
- Home/Map:
  - hero-блок с целью дня и процентом выполнения;
  - карта с цветными тайлами и динамикой захвата;
  - карточки активных челленджей;
  - быстрые действия: старт пробежки, открыть рейтинг, открыть награды.
- Active Run:
  - крупные метрики (дистанция, темп, время, калории);
  - live-progress к goal и к захвату зоны;
  - кнопки pause/resume/finish + защита от accidental tap;
  - GPS-status и fallback состояния.
- Run Result:
  - earned points, xp, territory gain;
  - новые ачивки/бейджи;
  - изменения позиции в рейтинге;
  - CTA для шаринга и запуска следующей цели.
- History + Run Details:
  - фильтры, сортировка, сравнение с лучшими результатами;
  - подробные сплиты и карта;
  - тренды прогресса по неделям.
- Leaderboard:
  - вкладки day/week/month + local/global/friends;
  - визуальный акцент на top-3;
  - подсветка своего места и прогресса до следующей позиции.
- Profile:
  - уровень, streak, рекорды, любимые дистанции;
  - витрина наград и процент закрытия коллекции.
- Settings:
  - аккаунт, уведомления, приватность, тема;
  - выбор визуальной схемы тайлов карты;
  - accessibility-переключатели.
- Future module (критично учесть): отдельный раздел **Achievements/Ачивки** с категориями, уровнями редкости (common/rare/epic), прогрессом, условиями разблокировки и экраном "achievement details".

## Компоненты
- Hero-card прогресса на главной
- Бейджи достижений (locked/unlocked)
- Карточки рангов и позиций в рейтинге
- Прогресс-кольца и линейные прогрессы
- Фильтры по периодам и типам активности
- Empty/error/loading состояния
- Tile legend + palette switcher для карты
- Reward modal и level-up modal

## Микроанимации
- Анимация получения достижения.
- Плавный апдейт счетчиков и прогресса.
- Легкая подсветка новой позиции в рейтинге.
- Короткая анимация перекраски тайла при захвате/потере территории.

## Ограничения и результат
- Mobile first (iOS + Android), сетка 8pt.
- Поддержать light/dark.
- Сгенерировать UI-kit + кликабельный прототип ключевых сценариев.
- Включить минимум 2 варианта цвета тайлов карты: основной и альтернативный.
