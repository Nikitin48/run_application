# Бесплатные и условно бесплатные AI для генерации интерфейсов

## Сервисы

- [Uizard](https://uizard.io/)  
  Есть free-план, быстро генерирует экраны по текстовому описанию.

- [Galileo AI](https://www.usegalileo.ai/)  
  Генерация UI по prompt, обычно доступен trial или free credits.

- [Visily](https://www.visily.ai/)  
  AI для wireframes и UI-макетов, есть бесплатный тариф для старта.

- [Figma AI](https://www.figma.com/ai/)  
  Удобно для итераций в Figma, доступ зависит от тарифа и региона.

- [Framer AI](https://www.framer.com/ai/)  
  Больше ориентирован на web UI, полезен для быстрых концептов.

- [Relume AI](https://www.relume.io/ai-site-builder)  
  Хорош для структуры и UI-блоков (веб), помогает проработать UX-композицию.

## Как лучше использовать

1. Сгенерировать 2-3 концепта в разных стилях.
2. Выбрать один визуальный язык.
3. Доработать в Figma как дизайн-систему (цвета, типографика, компоненты).
4. Проверить usability-сценарии: Start Run, Active Run, Result, History.
