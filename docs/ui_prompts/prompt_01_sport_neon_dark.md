# Prompt 01 — Sport Neon Dark

Сгенерируй мобильный интерфейс приложения **Run Application** в стиле **Sport Neon Dark**.

## Креативное направление
- Атмосфера: ночной город, скорость, адреналин, технологичность.
- Визуальный характер: темная база + яркие неоновые акценты.
- Новый дизайн с нуля, без референса на существующий интерфейс.

## Визуальная система
- Цвета:
  - фон: графитовый черный, глубокий синий;
  - акцент: neon lime + electric cyan;
  - статусы: успех (green), предупреждение (amber), ошибка (red).
- Контраст высокий, акценты только на важных действиях.
- Карточки полупрозрачные (glass-like), мягкие тени, radius 14-18.
- Типографика современная, крупные цифры для беговых метрик.
- Карта и тайлы территорий:
  - нейтральные тайлы: темно-серые/графитовые;
  - мои тайлы: neon lime;
  - тайлы соперников: electric cyan или violet;
  - contested (спорные): amber;
  - недоступные/скрытые: приглушенный серый.
- Добавь отдельный блок **Tile Color Rules**: цвета тайлов должны настраиваться через токены темы.

## UX приоритеты
- Главная кнопка "Start Run" всегда заметна.
- Все ключевые действия в 1-2 тапа.
- Во время активной пробежки минимализм и четкая читаемость.
- Безопасное завершение пробежки (подтверждение).
- Главный фокус интерфейса: "что делать сейчас" + "какой следующий шаг для прогресса".

## Обязательные экраны
1. Onboarding (3 экрана)
2. Login / Register
3. Home / Map
4. Active Run Tracking
5. Run Result
6. History
7. Run Details
8. Leaderboard
9. Profile
10. Settings

## Полный функционал приложения (должен быть отражен в UI)
- Онбординг: ценность приложения, объяснение территорий, персональные цели, разрешения (GPS/уведомления).
- Аутентификация: email + пароль, social login, восстановление пароля, валидация и состояния ошибок.
- Home/Map:
  - карта с тайлами территорий и легендой цветов;
  - текущая цель дня (дистанция/время/калории);
  - блок streak, прогресс недели, быстрый CTA "Start Run";
  - карточка челленджа дня и ближайшей награды.
- Active Run Tracking:
  - таймер, дистанция, темп, средний/текущий pace, калории;
  - кнопки pause/resume/finish + блокировка случайного нажатия;
  - состояния слабого GPS, потери сигнала и авто-паузы;
  - мини-карта маршрута и live-progress к цели.
- Run Result:
  - итоговые метрики, сравнение с прошлой пробежкой;
  - вклад в захват территорий;
  - прогресс к новому уровню и наградам;
  - CTA "Поделиться", "Повторить маршрут", "Перейти в историю".
- History и Run Details:
  - фильтры (дата, дистанция, время, темп, тип тренировки);
  - список пробежек с быстрым сканированием;
  - детальный экран с картой, сплитами, пульсом (если есть), зонами темпа.
- Leaderboard:
  - локальный/глобальный рейтинг;
  - вкладки day/week/month;
  - динамика позиции (+/-) и мотивационные подсказки.
- Profile:
  - аватар, уровень, streak, personal records;
  - статистика месяца/года;
  - блок "достижения" (текущие и будущие ачивки).
- Settings:
  - профиль, уведомления, приватность, безопасность, язык, тема;
  - управление источниками данных (HealthKit/Google Fit).
- Future module (обязательно учесть в архитектуре UI): отдельный раздел **Achievements/Ачивки** с экранами списка, деталей ачивки, прогресса и редкости.

## Компоненты
- Primary/Secondary/Destructive кнопки
- Bottom navigation (иконка + label)
- Карточки метрик
- Прогресс-кольца и прогресс-бары
- Фильтры (chips)
- Empty states, error states, loading skeletons
- Карточки достижений (locked/in progress/unlocked)
- Легенда карты + переключатель схемы цветов тайлов

## Микроанимации
- Плавная реакция кнопок на тап.
- Анимация роста прогресса и достижений.
- Мягкие переходы между состояниями таймера (run/pause/resume).
- Короткая анимация смены цвета тайла при захвате территории.

## Ограничения и результат
- Mobile first (iOS + Android), сетка 8pt.
- Дать light/dark, приоритет dark.
- Подготовить UI-kit + кликабельный прототип ключевых потоков.
- Обязательно: показать минимум 1 экран/оверлей с альтернативной цветовой схемой тайлов карты.
