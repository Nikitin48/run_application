# Prompt 01 — Sport Neon Dark

Сгенерируй мобильный интерфейс приложения **Run Application** в стиле **Sport Neon Dark**.

## Креативное направление
- Атмосфера: ночной город, скорость, адреналин, технологичность.
- Визуальный характер: темная база + яркие неоновые акценты.
- Новый дизайн с нуля, без референса на существующий интерфейс.

## Визуальная система
- Цвета:
  - фон: графитовый черный, глубокий синий;
  - акцент: neon lime + electric cyan;
  - статусы: успех (green), предупреждение (amber), ошибка (red).
- Контраст высокий, акценты только на важных действиях.
- Карточки полупрозрачные (glass-like), мягкие тени, radius 14-18.
- Типографика современная, крупные цифры для беговых метрик.

## UX приоритеты
- Главная кнопка "Start Run" всегда заметна.
- Все ключевые действия в 1-2 тапа.
- Во время активной пробежки минимализм и четкая читаемость.
- Безопасное завершение пробежки (подтверждение).

## Обязательные экраны
1. Onboarding (3 экрана)
2. Login / Register
3. Home / Map
4. Active Run Tracking
5. Run Result
6. History
7. Run Details
8. Leaderboard
9. Profile
10. Settings

## Компоненты
- Primary/Secondary/Destructive кнопки
- Bottom navigation (иконка + label)
- Карточки метрик
- Прогресс-кольца и прогресс-бары
- Фильтры (chips)
- Empty states, error states, loading skeletons

## Микроанимации
- Плавная реакция кнопок на тап.
- Анимация роста прогресса и достижений.
- Мягкие переходы между состояниями таймера (run/pause/resume).

## Ограничения и результат
- Mobile first (iOS + Android), сетка 8pt.
- Дать light/dark, приоритет dark.
- Подготовить UI-kit + кликабельный прототип ключевых потоков.
