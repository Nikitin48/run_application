# Run Application — базовый промпт

Создай новый интерфейс мобильного приложения **Run Application** (трекинг пробежек + геймификация территорий). Не повторяй существующий дизайн, ориентируйся на актуальные UI/UX-практики.

## Продукт
- Пользователь: запускает пробежку, видит маршрут и метрики, захватывает территории, следит за историей, рейтингом и профилем.
- Эмоция: **энергия, прогресс, соревнование, достижение**.
- Стиль: **современный minimal + sport tech**, готовый к расширению (новые модули).

## Визуальная система
- Подход: чистая сетка, крупная типографика, заметные CTA, высокий контраст.
- Цвета (пример): темный графит / индиго + неоновый лайм или electric blue, статусные цвета.
- Поддержать light/dark, приоритет — dark.
- Карта и тайлы:
  - минимум 5 состояний: neutral, mine, opponent, contested, disabled;
  - цвета тайлов вынести в tokens, чтобы можно было менять палитру;
  - предусмотреть альтернативную цветовую схему тайлов (настройки/карта).

## UX принципы
- Главные сценарии в 1–2 тапа: начать пробежку, увидеть результат, понять прогресс.
- Структура: onboarding → auth → home/map → run tracking → result → history/profile.
- Дружелюбные empty/error-состояния и базовая accessibility (контраст, размер тапа, читабельность).

## Экраны (сгенерировать)
1. **Onboarding (3 экрана)** — ценность, территории, мотивация и статистика.
2. **Auth** — login/registration, базовая валидация.
3. **Home / Map** — карта с тайлами, статус, заметная кнопка "Start Run".
4. **Active Run Tracking** — таймер, дистанция, темп, калории, pause/resume/finish с подтверждением.
5. **Run Result** — итог забега, прогресс достижений, вклад в территорию/рейтинг.
6. **History** — список пробежек с фильтрами.
7. **Run Details** — карта маршрута и детальная статистика.
8. **Leaderboard** — глобальный/локальный рейтинг, вкладки периодов.
9. **Profile** — аватар, level, streak, personal records, блок достижений.
10. **Settings** — тема, уведомления, язык, приватность, безопасность.

### Краткий функционал по модулям
- Onboarding — объясни ценность, механику захвата территорий и зачем нужны ачивки.
- Home/Map — всегда показывай цель дня, прогресс недели, легенду тайлов и CTA "Start Run".
- Active Run — крупные метрики, индикатор GPS, защита от случайного завершения забега.
- Result — сравнение с прошлым забегом, влияние на рейтинг и прогресс ачивок.
- History/Run Details — фильтры, список пробежек, карта маршрута и сплиты.
- Leaderboard — вкладки по периодам, подсветка собственной позиции.
- Profile — личная статистика, streak, рекорды и витрина достижений.

## Ачивки (future-ready)
- Отдельный раздел **Achievements/Ачивки**.
- Экраны: список, категории, детали ачивки, прогресс.
- Поддержать редкость (например: common/rare/epic/legendary) и связи с действиями пользователя (дистанция, частота, захват территорий).

## Компоненты
- Кнопки (primary/secondary/ghost/destructive), поля ввода (default/error/success).
- Chips/filters, tabs, bottom navigation.
- Карточки пробежки и достижений, progress bars/rings.
- Toast/snackbar/alert, skeletons и empty/error-состояния.
- Компонент легенды карты и состояний тайлов.

## Технические требования
- Mobile first (iOS + Android), сетка 8pt.
- Auto-layout/constraints.
- Дизайн-токены для цветов, отступов, радиусов, типографики.
- Интерактивный прототип ключевых пользовательских потоков.
