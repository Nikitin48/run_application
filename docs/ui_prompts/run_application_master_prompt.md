# Run Application — базовый промпт для генерации интерфейса

Создай современный, визуально чистый и эмоционально мотивирующий интерфейс мобильного приложения **Run Application** (трекинг пробежек + геймификация территорий).

**Важно:** не используй и не повторяй существующий дизайн. Нужен полностью новый визуальный язык с фокусом на UI/UX best practices 2026.

## 1) Продукт и идея
- Приложение для бегунов, где пользователь:
  - запускает пробежку;
  - видит маршрут, метрики и прогресс;
  - захватывает территории;
  - следит за историей, рейтингом и профилем.
- Эмоция продукта: **энергия, прогресс, соревнование, достижение**.
- Стиль: **современный minimal + premium sport tech**.

## 2) Целевая аудитория
- 18–40 лет, активные пользователи, любящие фитнес и челленджи.
- Ожидания: быстрый старт пробежки, понятные метрики, заметный прогресс, удобство одной рукой.

## 3) UI стиль и визуальная система
- Подход: **clean layout, крупная типографика, акцентные CTA, высокий контраст**.
- Цвета:
  - база: темный графит / глубокий индиго;
  - акцент: неоновый лайм или electric blue;
  - поддержка: белый, мягкие серые, статусные цвета (success/warning/error).
- Поддержать **light и dark theme**, приоритет — dark.
- Компоненты: карточки с мягким радиусом, четкие иерархии, минимум визуального шума.
- Анимации: мягкие micro-interactions (нажатия, прогресс, переключения вкладок), без перегруза.
- Иконки: единый стиль outline + filled для активного состояния.

## 4) UX принципы
- Главные действия доступны в 1–2 тапа.
- Критичные сценарии: "начать пробежку", "посмотреть результат", "понять прогресс".
- Понятная структура: onboarding -> auth -> home/map -> run tracking -> result -> history/profile.
- Ошибки и пустые состояния должны быть дружелюбными и полезными.
- Accessibility: контраст, тап-зоны не менее 44px, читабельная типографика.

## 5) Экраны (сгенерировать полный набор)
1. **Onboarding (3 экрана)**: ценность, геймификация территорий, мотивация и статистика.
2. **Auth**: login/registration (переключатель), понятные поля, validation states.
3. **Home / Map**: карта как главный фокус, текущий статус, заметная кнопка "Start Run".
4. **Active Run Tracking**: таймер, дистанция, темп, калории, pause/resume/finish, подтверждение завершения.
5. **Run Result**: итоги пробежки, прогресс достижений, вклад в территорию/рейтинг.
6. **History**: список пробежек, фильтры (дата, дистанция, темп), ключевые метрики.
7. **Run Details**: маршрут на карте, детальная статистика и сплиты.
8. **Leaderboard**: глобальный/локальный рейтинг, tabs: день/неделя/месяц.
9. **Profile**: аватар, level, streak, achievements, personal records.
10. **Settings**: приватность, уведомления, язык, тема, безопасность.

## 6) Компонентная библиотека
Сгенерируй UI-kit:
- кнопки (primary/secondary/ghost/destructive),
- поля ввода (default/error/success),
- chips/filters,
- tabs и bottom navigation,
- карточки пробежки/достижения,
- progress bars/rings,
- toast/snackbar/alert,
- skeleton loaders и empty states.

## 7) Тон и контент
- Короткие мотивирующие тексты интерфейса.
- Микрокопирайт: "Продолжай", "Новый рекорд близко", "Еще 1 км до цели".
- Избегать перегруженных формулировок.

## 8) Технические требования к макетам
- Платформа: mobile first (iOS + Android).
- Сетка: 8pt.
- Auto-layout / constraints.
- Подготовь дизайн-систему токенов: color, spacing, radius, typography.
- Предоставь интерактивный прототип ключевых пользовательских потоков.
