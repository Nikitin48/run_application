ПРИМЕР ВЫЗОВА ФУНКЦИИ
=====================

-- Создаем тестовый трек (прямоугольник)
WITH test_track AS (
  SELECT ST_SetSRID(
    ST_GeomFromText(
      'LINESTRING(37.62 55.75, 37.63 55.75, 37.63 55.76, 37.62 55.76, 37.62 55.75)'
    ),
    4326
  ) AS track_line
)
SELECT 
  ST_AsText(compute_capture_polygons(track_line, 10, 150)) AS result
FROM test_track;

-- Результат:
-- MULTIPOLYGON(((37.62 55.75, 37.63 55.75, 37.63 55.76, 37.62 55.76, 37.62 55.75)))


В КОНТЕКСТЕ ПРИЛОЖЕНИЯ
======================

1. Пользователь бежит с приложением
   │
   ▼
2. GPS записывает точки: A → B → C → D → E → (почти A)
   │
   ▼
3. Пользователь завершает пробежку → POST /runs/finish
   │
   ▼
4. Backend сохраняет трек в БД (таблица runs, поле track_line)
   │
   ▼
5. Вызывается finalize_run_capture(run_id)
   │
   ▼
6. Внутри вызывается compute_capture_polygons(track_line, 10, 150)
   │
   ├─→ Transform to 3857
   ├─→ Snap (замыкание)
   ├─→ Node (разбиение)
   ├─→ Polygonize (полигоны)
   ├─→ Filter (по площади)
   └─→ Transform to 4326
   │
   ▼
7. Получаем MultiPolygon (захваченные территории)
   │
   ▼
8. Используем для перераспределения:
   - Находим жертв (ST_Intersects)
   - Убираем у жертв (ST_Difference)
   - Добавляем бегуну (ST_Union)
   │
   ▼
9. Обновляем статистику и уведомления
   │
   ▼
10. Пользователь видит захваченную территорию на карте!
