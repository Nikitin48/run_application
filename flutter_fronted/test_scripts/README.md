# Скрипты для тестирования фонового трекинга

## Проблема
Нужно проверить, что приложение записывает GPS-точки, когда свёрнуто или экран выключен.

## Android (эмулятор)

### Способ 1: ADB скрипт (рекомендуется)
```bash
chmod +x simulate_run_android.sh
./simulate_run_android.sh
```

**Порядок тестирования:**
1. Запустить Android эмулятор
2. Открыть приложение, начать пробежку
3. Свернуть приложение (Home)
4. Запустить скрипт в терминале
5. Подождать ~1-2 минуты
6. Открыть приложение — маршрут должен быть прорисован

### Способ 2: Mock Location (реальное устройство)
1. Включить "Режим разработчика" на телефоне
2. Установить "Fake GPS Location" из Play Store
3. В настройках разработчика: "Select mock location app" → выбрать Fake GPS
4. Запустить пробежку → свернуть → двигать точку в Fake GPS

## iOS (симулятор)

### Способ 1: GPX файл через Xcode
1. Открыть `ios/Runner.xcworkspace` в Xcode
2. Перетащить `simulated_run.gpx` в проект Xcode
3. Запустить приложение на симуляторе
4. Начать пробежку → свернуть (Cmd+Shift+H)
5. В Xcode: **Debug → Simulate Location → simulated_run**
6. Подождать ~3 минуты, открыть приложение

### Способ 2: Встроенная симуляция Xcode
1. В Xcode: **Debug → Simulate Location → City Run**
2. Это запустит предустановленный маршрут по городу

## Что проверять

- [ ] Маршрут записался (видна полилиния на карте)
- [ ] Точки не "склеились" (нет прямой линии от точки сворачивания до точки раскрытия)
- [ ] Уведомление "Идет пробежка" видно в шторке (Android)
- [ ] Синий индикатор геолокации виден в статус-баре (iOS)
- [ ] Финиш пробежки работает из уведомления (Android)
